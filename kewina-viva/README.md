# Kewiña Viva · Presentación ejecutiva para CAF

Presentación interactiva del proyecto «Kewiña Viva: turismo de naturaleza para sostener la restauración de los bosques de kewiña en el Tunari» (Chiaraje, Cocapata, Cochabamba, Bolivia).

## Publicar con GitHub Pages

1. Sube todo el contenido de esta carpeta a la raíz del repositorio, con `index.html` y la carpeta `img/`.
2. En el repositorio, ve a **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarda.
4. En uno o dos minutos la presentación estará en `https://<usuario>.github.io/<repositorio>/`.

## Uso

- Flechas ← → o los botones de abajo para avanzar.
- El menú **Índice** muestra todas las láminas por fase.
- Toca los puntos y tarjetas con ⋯ para ver más información. Los popups se pueden arrastrar.

## Notas

- Necesita conexión a internet para cargar las fuentes (Google Fonts) y la librería de animación GSAP (jsDelivr).
- El modelo de la kewiña de la lámina 3 parte de una fotografía de Vedoble.Ve. Hace falta su permiso antes de publicar.
- Las fotos de las Warmi Kewiñas muestran a personas identificables. Confirma su consentimiento antes de hacer público el repositorio.
